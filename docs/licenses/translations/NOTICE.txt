Translation tools and model attribution

Original error descriptions retain the author, source URL, license and modification notices shown on each code page. Translations are derivative explanatory copies, not official vendor translations. The English original is preserved for technical interpretation.

Google Translate produced the Korean, Japanese, Chinese, Spanish and German descriptions and an initial subset of French descriptions. The remaining French, Portuguese and Russian descriptions were generated offline with OPUS-MT models using CTranslate2. Per-description provider names are retained in the translation data and displayed beside translations. No translation service is called when a visitor opens a page or searches.

Original model creator: Language Technology Research Group, University of Helsinki / Helsinki-NLP, OPUS-MT contributors.
