Error 524: a timeout occurred

Andere Schreibweisen: Error 524

Was bedeutet dieser Code?

Code 524 · Ein von Cloudflare HTTP errors gemeldetes Problem.

Übersetzte Erklärung

Fehler 524 weist darauf hin, dass Cloudflare erfolgreich eine Verbindung zum Ursprungswebserver hergestellt hat, der Ursprung jedoch keine HTTP-Antwort vor dem standardmäßigen Proxy-Lese-Timeout von 125 Sekunden bereitgestellt hat. Dies kann passieren, wenn der Ursprungsserver zu lange benötigt, weil er zu viel Arbeit zu erledigen hat, beispielsweise eine große Datenabfrage, oder weil der Server Ressourcenknappheit hat und keine Daten rechtzeitig zurückgeben kann. Der Fehler 524 tritt auf, wenn der Ursprungswebserver die Ressourcenanforderung nach dem Verbindungsaufbau bestätigt (ACK), aber keine rechtzeitige Antwort sendet (innerhalb der Proxy-Lese-Timeout-Verzögerung, standardmäßig 125 Sekunden).

Offizielle Erklärung · Originaltext

Error 524 indicates that Cloudflare successfully connected to the origin web server, but the origin did not provide an HTTP response before the default 125 seconds Proxy Read Timeout. This can happen if the origin server is taking too long because it has too much work to do, for example, a large data query, or because the server is struggling for resources and cannot return any data in time. The error 524 occurs if the origin web server acknowledges (ACK) the resource request after the connection has been established, but does not send a timely response (within the Proxy Read Timeout delay, 125 seconds by default).
