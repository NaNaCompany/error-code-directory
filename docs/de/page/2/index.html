  • 1102Error 1102
    Error 1102: Worker exceeded resource limits

    Dieser Fehler weist darauf hin, dass ein Cloudflare-Worker sein CPU-Zeitlimit oder sein Speicherlimit überschritten hat. Ein Cloudflare-Worker überschreitet ein CPU-Zeitlimit. Die CPU-Zeit ist die Zeit, die für die Ausführung von Code aufgewendet wird (z. B. Schleifen, JSON-Analyse usw.). Die für Netzwerkanfragen (Abrufen, Antworten) aufgewendete Zeit zählt nicht zur CPU-Zeit.

    CloudflareCloudflare HTTP errors
  • 1104Error 1104
    Error 1104: A variation of this email address is already taken in our system. Only one variation is allowed.

    Dieser Fehler weist darauf hin, dass die E-Mail-Adresse, die Sie hinzufügen möchten, bereits im System vergeben ist. Dieser Fehler kann auftreten, wenn eine E-Mail mit einer Variation der E-Mail hinzugefügt wurde, die Sie hinzufügen möchten. Beispielsweise werden my+user@example.com und my.user@example.com in unserem System gleich behandelt.

    CloudflareCloudflare HTTP errors

Am Cloudflare-Edge stehen zu viele Anfragen in der Warteschlange, die auf die Verarbeitung durch Ihren Ursprungswebserver warten. Dieses Limit schützt die Systeme von Cloudflare.
