  • SQLITE_INTERNAL2

Wenn die Anwendung auf diesen Ergebniscode stößt, weist dies darauf hin, dass ein Fehler in der Datenbank-Engine vorliegt. Dieser Ergebniscode könnte durch einen Fehler in SQLite verursacht werden. Allerdings können auch anwendungsdefinierte SQL-Funktionen oder virtuelle Tabellen oder VFSes oder andere Erweiterungen dazu führen, dass dieser Ergebniscode zurückgegeben wird, sodass das Problem möglicherweise nicht auf den Kern von SQLite zurückzuführen ist.
