    BadResourceRequest

    BadResourceRequest – Um den Code für ein Zugriffstoken einzulösen, sollte die App eine POST-Anfrage an den /token-Endpunkt senden. Zuvor sollten Sie außerdem einen Autorisierungscode bereitstellen und diesen in der POST-Anfrage an den /token-Endpunkt senden. In diesem Artikel finden Sie einen Überblick über den Ablauf des OAuth 2.0-Autorisierungscodes. Leiten Sie den Benutzer zum Endpunkt /authorize, der einen Authorization_code zurückgibt. Durch das Senden einer Anfrage an den /token-Endpunkt erhält der Benutzer das Zugriffstoken. Überprüfen Sie App-Registrierungen > Endpunkte, um zu bestätigen, dass die beiden Endpunkte korrekt konfiguriert wurden.

  • AADSTS9007290072
    PassThroughUserMfaError

    PassThroughUserMfaError – Das externe Konto, mit dem sich der Benutzer anmeldet, ist auf dem Mandanten, bei dem er sich angemeldet hat, nicht vorhanden. Daher kann der Benutzer die MFA-Anforderungen für den Mandanten nicht erfüllen. Dieser Fehler kann auch auftreten, wenn die Benutzer synchronisiert sind, aber eine Nichtübereinstimmung im ImmutableID-Attribut (sourceAnchor) zwischen Active Directory und Microsoft Entra ID besteht. Das Konto muss zunächst als externer Benutzer im Mandanten hinzugefügt werden. Melden Sie sich ab und melden Sie sich mit einem anderen Microsoft Entra-Benutzerkonto an. Weitere Informationen finden Sie unter Konfigurieren externer Identitäten.
