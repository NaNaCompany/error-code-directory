    ERROR_INCOMPATIBLE_SERVICE_SID_TYPE

    Der Dienststart ist fehlgeschlagen, da einer oder mehrere Dienste im selben Prozess eine inkompatible Einstellung für den Dienst-SID-Typ haben. Ein Dienst mit eingeschränktem Dienst-SID-Typ kann im selben Prozess nur mit anderen Diensten mit eingeschränktem SID-Typ koexistieren. Wenn der Dienst-SID-Typ für diesen Dienst gerade konfiguriert wurde, muss der Hosting-Prozess neu gestartet werden, um diesen Dienst zu starten. Unter Windows Server 2003 und Windows XP kann ein uneingeschränkter Dienst nicht im selben Prozess mit anderen Diensten koexistieren. Der Dienst mit dem uneingeschränkten Dienst-SID-Typ muss in einen eigenen Prozess verschoben werden, um diesen Dienst zu starten.
