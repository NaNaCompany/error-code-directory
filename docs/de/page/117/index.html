  • BaseExceptionGroup
    BaseExceptionGroup

    Beide Ausnahmetypen umschließen die Ausnahmen in der Sequenz excs. Der msg-Parameter muss eine Zeichenfolge sein. Der Unterschied zwischen den beiden Klassen besteht darin, dass BaseExceptionGroup BaseException erweitert und jede Ausnahme umschließen kann, während ExceptionGroup Exception erweitert und nur Unterklassen von Exception umschließen kann. Dieses Design ist so konzipiert, dass außer Exception eine ExceptionGroup abfängt, nicht jedoch BaseExceptionGroup. Der BaseExceptionGroup-Konstruktor gibt eine ExceptionGroup statt einer BaseExceptionGroup zurück, wenn alle enthaltenen Ausnahmen Ausnahmeinstanzen sind, sodass er verwendet werden kann, um die Auswahl automatisch vorzunehmen. Der ExceptionGroup-Konstruktor hingegen löst einen TypeError aus, wenn eine enthaltene Ausnahme keine Exception-Unterklasse ist. Ausnahmegruppen sind hinsichtlich des Typs ihrer enthaltenen Ausnahmen generisch. Beachten Sie, dass BaseExceptionGroup __new__() definiert. Daher müssen Unterklassen, die eine andere Konstruktorsignatur benötigen, diese überschreiben und nicht __init__(). Im Folgenden wird beispielsweise eine Unterklasse einer Ausnahmegruppe definiert, die einen Exit_code akzeptiert und daraus die Nachricht der Gruppe erstellt. Wie ExceptionGroup kann jede Unterklasse von BaseExceptionGroup, die auch eine Unterklasse von Exception ist, nur Instanzen von Exception umschließen.

    PythonPython
