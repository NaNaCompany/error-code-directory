  • HPE_HEADER_OVERFLOW
    hpe header overflow

    Es wurden zu viele HTTP-Header-Daten empfangen. Wenn zum Schutz vor böswilligen oder falsch konfigurierten Clients mehr als maxHeaderSize an HTTP-Headerdaten empfangen werden, wird die HTTP-Analyse abgebrochen, ohne dass ein Anforderungs- oder Antwortobjekt erstellt wird, und ein Fehler mit diesem Code wird ausgegeben.

    Node.jsNode.js
  • HPE_UNEXPECTED_CONTENT_LENGTH
    hpe unexpected content length

    Der Server sendet sowohl einen Content-Length-Header als auch Transfer-Encoding: chunked. Transfer-Encoding: Chunked ermöglicht es dem Server, eine dauerhafte HTTP-Verbindung für dynamisch generierte Inhalte aufrechtzuerhalten. In diesem Fall kann der Content-Length-HTTP-Header nicht verwendet werden. Verwenden Sie Content-Length oder Transfer-Encoding: chunked.
