隐私与搜索处理

代码搜索

下载代码列表后，搜索和筛选均在浏览器中进行。搜索词不会提交至服务器，也不会记录在 URL 中。本站不提供文件上传、账号或密码输入功能。

访问统计与广告

公开部署的页面使用 Google Analytics 4、Google Tag Manager、Google AdSense 和 Cloudflare Web Analytics。这些服务可能按各自政策处理连接信息、设备信息、Cookie 等数据。本应用不会创建向这些服务发送搜索词或输入值的事件。GA4 的页面地址不含查询字符串和片段。 本地开发服务器会移除分析及广告脚本，并阻止外部请求。
