官方说明 · 原文

Cloudflare Workers returns a 501 error when a request uses an HTTP method that is not supported by the Workers Runtime. - A client sent a request to a Workers script using a custom or non-standard HTTP method (methods outside of GET, POST, PUT, etc.). - A typo in the HTTP method (for example, POT instead of POST).
