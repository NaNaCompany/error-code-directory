  • BaseExceptionGroup
    BaseExceptionGroup

    Ambos os tipos de exceção envolvem as exceções na sequência excs. O parâmetro msg deve ser uma string. A diferença entre as duas classes é que BaseExceptionGroup estende BaseException e pode envolver qualquer exceção, enquanto ExceptionGroup estende Exceção e só pode envolver subclasses de Exceção. Este projeto é de modo que exceto Exceção captura um ExcetionGroup mas não BaseExceptionGroup. O construtor BaseExceptionGroup retorna um ExcetionGroup em vez de um BaseExceptionGroup se todas as exceções contidas são instâncias de Exceção, por isso pode ser usado para fazer a seleção automática. O construtor ExceptionGroup, por outro lado, levanta um TipoError se qualquer exceção contida não é uma subclasse de Exceção. Os grupos de exceção são genéricos sobre o tipo de suas exceções contidas.
