72

ERROR_REDIR_PAUSED

Alternative forms: 0x00000048 · 0x48 · ERROR_REDIR_PAUSED · 0x80070048

What does this code mean?

Code 72 · An issue reported by Windows Win32.

Official explanation · Original text

The specified printer or disk device has been paused.
