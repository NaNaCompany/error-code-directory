Privacy and search processing

Code search

After the code list is downloaded, searches and filters run in your browser. Search terms are not submitted to a server or recorded in the URL. There are no file upload, account, or password input features.

Analytics and advertising

Publicly deployed pages use Google Analytics 4, Google Tag Manager, Google AdSense, and Cloudflare Web Analytics. These services may process connection and device information, cookies, and similar data under their own policies. This app does not create events that send search terms or input values to these services. GA4 page addresses exclude query strings and fragments. The local development server removes analytics and advertising scripts and blocks external requests.

Google Privacy Policy · Cloudflare Privacy Policy

External links

Official troubleshooting documents open on external sites. The shared book banner links to an external bookstore; search terms are not passed to the banner.
