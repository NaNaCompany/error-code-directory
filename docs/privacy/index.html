코드 검색

코드 목록을 내려받은 뒤 검색·필터는 브라우저에서 처리합니다. 검색어를 서버에 제출하거나 URL에 기록하지 않습니다. 파일 업로드·계정·비밀번호 입력 기능은 없습니다.

접속 통계·광고

공개 배포 페이지는 Google Analytics 4, Google Tag Manager, Google AdSense, Cloudflare Web Analytics를 사용합니다. 서비스는 접속·기기 정보와 쿠키 등을 각 정책에 따라 처리할 수 있습니다. 이 앱은 검색어와 입력값을 이들 서비스에 전송하는 이벤트를 만들지 않습니다. GA4의 페이지 주소는 쿼리와 해시를 제외합니다. 로컬 개발 서버는 분석·광고 스크립트를 제거하고 외부 요청을 차단합니다.

Google 개인정보처리방침 · Cloudflare 개인정보처리방침

외부 링크

공식 해결 문서는 외부 사이트로 이동합니다. 공유 도서 배너는 외부 서점으로 연결되며, 검색어를 배너에 전달하지 않습니다.

출처·수집 범위 · 라이선스 · 개인정보 · 사이트맵

공식 문서 기반 코드 참고 자료. 환경·제품 버전에 따라 의미와 조치가 달라질 수 있습니다.
