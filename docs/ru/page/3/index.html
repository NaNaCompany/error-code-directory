  • OUT_OF_RANGE11 · google.rpc.Code.OUT_OF_RANGE
    OUT OF RANGE

    В отличие от "INVALID_ARGUTE" эта ошибка указывает на проблему, которая может быть установлена, если состояние системы изменится. Например, 32-битная файловая система будет генерировать "INVALID_ARGUINT" при необходимости читать на перемежевании, которое не находится в диапазоне [0,2°32-1], но она будет генерировать "Out_OF_RANGE", если ее попросят прочитать из зачета текущего размера файла. Существует некоторое совпадение между "FAILED_PREDION" и "OUT_OF_RANGE". Мы рекомендуем использовать "OUT_OF_RANGE" (более конкретная ошибка), когда она применяется таким образом, чтобы звонящие, которые впитывают его через площадку, имели возможность пользоваться возможностью. Легко найти ошибку "Out_OF_RANGE", чтобы обнаружить, когда она сделана. HTTP Картирование: 400 Плохой запрос
