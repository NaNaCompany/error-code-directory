  • ERR_REQUIRE_CYCLE_MODULE
    require cycle module

    При попытке потребовать () модуля ES в непосредственном цикле участвует общий JS в ЭSM или ESM в общих JS. Это не допускается, поскольку модули ES не могут быть оценены в то время, когда они уже оцениваются. Для того чтобы избежать этого цикла, запрос(а), связанный(ые) с циклом, не должен(ы) происходить на верхнем уровне ни модуля ES (через создание модуля Require()), ни модуля общего JS и должен выполняться лазиально в рамках внутренней функции.
