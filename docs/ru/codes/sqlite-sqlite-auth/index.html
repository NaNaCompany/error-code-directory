Что означает этот код?

Код SQLITE_AUTH · Проблема, о которой сообщает SQLite.

Перевод описания

Ошибка SQLITE_AUTH возвращается, когда ответный звонок уполномоченного указывает на то, что заявление SQL, которое готовится, не разрешено.

OPUS-MT · Helsinki-NLP / CTranslate2 · Это автоматический перевод. Технические термины и условия применения сверяйте с английским оригиналом.

Официальное описание · Оригинал

The SQLITE_AUTH error is returned when the authorizer callback indicates that an SQL statement being prepared is not authorized.
