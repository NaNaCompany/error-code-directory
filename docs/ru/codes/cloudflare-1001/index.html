Error 1001: DNS resolution error

Другие формы записи: Error 1001

Что означает этот код?

Код 1001 · Проблема, о которой сообщает Cloudflare HTTP errors.

Перевод описания

Эта ошибка указывает на неудачу решения DNS, препятствующую доступу в запрашиваемый домен. - Запрос на веб-адрес Cloudflare IP для несуществующего домена Cloudflare. - Внешний домен, который не использует Cloudflare, имеет запись CNAME в домене, активно действующей на Cloudflare - Цель записи DNS CNAME не решается. - рекорд CNAME в вашем Cloudflare DNS-приложения требует разрешения с помощью DNS-провайдера, который в настоящее время не работает.

Официальное описание · Оригинал

This error indicates a DNS resolution failure preventing access to the requested domain. - A web request was sent to a Cloudflare IP address for a non-existent Cloudflare domain. - An external domain that is not on using Cloudflare has a CNAME record to a domain active on Cloudflare - The target of the DNS CNAME record does not resolve. - A CNAME record in your Cloudflare DNS app requires resolution via a DNS provider that is currently offline.
