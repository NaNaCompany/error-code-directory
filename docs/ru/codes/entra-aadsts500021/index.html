AADSTS500021

Access to '{tenant}' tenant is denied

Другие формы записи: 500021

Что означает этот код?

Код AADSTS500021 · Проблема, о которой сообщает Microsoft Entra ID.

Перевод описания

Доступ к арендатору " {арендатору} не доступен. AADSTS 500021 указывает, что функция ограничения арендатора построена и что пользователь пытается получить доступ к арендатору, который не включен в список квартиросъемщиков, указанный в заголовке "ограничить доступ к тенанту". Более подробную информацию см. в разделе "Употребить ограничения на доступ арендаторов к облачным приложениям Saas".

Официальное описание · Оригинал

Access to '{tenant}' tenant is denied. AADSTS500021 indicates that the tenant restriction feature is configured and that the user is trying to access a tenant that isn't in the list of allowed tenants specified in the header Restrict-Access-To-Tenant. For more information, see Use tenant restrictions to manage access to SaaS cloud applications.
