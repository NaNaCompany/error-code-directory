ERR_HTTP2_INVALID_INFO_STATUS

http2 invalid info status

Что означает этот код?

Код ERR_HTTP2_INVALID_INFO_STATUS · Проблема, о которой сообщает Node.js.

Перевод описания

Недействительный код информационного статуса HTTP должен быть целым от 100 до 199 (включающим).

OPUS-MT · Helsinki-NLP / CTranslate2 · Это автоматический перевод. Технические термины и условия применения сверяйте с английским оригиналом.

Официальное описание · Оригинал

An invalid HTTP informational status code has been specified. Informational status codes must be an integer between 100 and 199 (inclusive).
