SQLITE_IOERR_SHMSIZE

ioerr shmsize

Другие формы записи: 4874

Что означает этот код?

Код SQLITE_IOERR_SHMSIZE · Проблема, о которой сообщает SQLite.

Перевод описания

SQLITE_IOERR_SHMSIZE — расширенный код ошибки для SQLITE_IOERR, указывающий на ошибку I/O в методе xShmMap на объекте квадратного уровня 3_io_методы, в то же время пытаясь расширить файл "shm" в рамках обработки режима WAL. Эта ошибка может указывать на то, что базовый объем файловой системы выведен из пространства.

OPUS-MT · Helsinki-NLP / CTranslate2 · Это автоматический перевод. Технические термины и условия применения сверяйте с английским оригиналом.

Официальное описание · Оригинал

The SQLITE_IOERR_SHMSIZE error code is an extended error code for SQLITE_IOERR indicating an I/O error within the xShmMap method on the sqlite3_io_methods object while trying to enlarge a "shm" file as part of WAL mode transaction processing. This error may indicate that the underlying filesystem volume is out of space.
