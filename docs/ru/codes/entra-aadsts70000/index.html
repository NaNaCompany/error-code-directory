AADSTS70000

InvalidGrant

Другие формы записи: 70000

Что означает этот код?

Код AADSTS70000 · Проблема, о которой сообщает Microsoft Entra ID.

Перевод описания

Неверный Grant - Autentification не удалось. Символ обновления недействителен. Ошибка может объясняться следующими причинами: Токен связывающий заголовок пустой токен связывающий хэш не соответствует

OPUS-MT · Helsinki-NLP / CTranslate2 · Это автоматический перевод. Технические термины и условия применения сверяйте с английским оригиналом.

Официальное описание · Оригинал

InvalidGrant - Authentication failed. The refresh token isn't valid. Error might be due to the following reasons: Token binding header is empty Token binding hash does not match
