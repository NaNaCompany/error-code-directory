    BadResourceRequest

    BadResourceRequest: para canjear el código por un token de acceso, la aplicación debe enviar una solicitud POST al punto final /token. Además, antes de esto, debe proporcionar un código de autorización y enviarlo en la solicitud POST al punto final /token. Consulte este artículo para obtener una descripción general del flujo del código de autorización de OAuth 2.0. Dirija al usuario al punto final /authorize, que devolverá un código de autorización. Al publicar una solicitud en el punto final /token, el usuario obtiene el token de acceso. Verifique Registros de aplicaciones > Puntos finales para confirmar que los dos puntos finales se configuraron correctamente.

    BadResourceRequestInvalidRequest

    BadResourceRequestInvalidRequest: el punto final solo acepta solicitudes {valid_verbs}. Se recibió una solicitud {invalid_verb}. {valid_verbs} representa una lista de verbos HTTP admitidos por el punto final (por ejemplo, POST), {invalid_verb} es un verbo HTTP utilizado en la solicitud actual (por ejemplo, GET). Esto puede deberse a un error del desarrollador o a que los usuarios presionen el botón Atrás en su navegador, lo que generó una solicitud incorrecta. Se puede ignorar.
