¿Qué problema indica?

Código ModuleNotFoundError · Problema informado por Python.

Explicación traducida

Una subclase de ImportError que la importación genera cuando no se puede localizar un módulo. También aparece cuando no se encuentra Ninguno en sys.modules.

Explicación oficial · Texto original

A subclass of ImportError which is raised by import when a module could not be located. It is also raised when None is found in sys.modules.
