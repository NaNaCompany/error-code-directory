AADSTS700082

ExpiredOrRevokedGrantInactiveToken

Otras formas: 700082

¿Qué problema indica?

Código AADSTS700082 · Problema informado por Microsoft Entra ID.

Explicación traducida

ExpiredOrRevokedGrantInactiveToken: el token de actualización expiró debido a inactividad. El token se emitió el {issueDate} y estuvo inactivo durante {time}. Parte esperada del ciclo de vida del token: el usuario pasó un período prolongado sin usar la aplicación, por lo que el token caducó cuando la aplicación intentó actualizarlo.

Google Translate · Esta es una traducción automática. Consulte el original en inglés para comprobar los términos técnicos y las condiciones aplicables.

Explicación oficial · Texto original

ExpiredOrRevokedGrantInactiveToken - The refresh token has expired due to inactivity. The token was issued on {issueDate} and was inactive for {time}. Expected part of the token lifecycle - the user went an extended period of time without using the application, so the token was expired when the app attempted to refresh it.
