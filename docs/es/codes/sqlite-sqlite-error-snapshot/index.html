SQLITE_ERROR_SNAPSHOT

error snapshot

Otras formas: 769

¿Qué problema indica?

Código SQLITE_ERROR_SNAPSHOT · Problema informado por SQLite.

Explicación traducida

Es posible que se devuelva el código de resultado SQLITE_ERROR_SNAPSHOT al intentar iniciar una transacción de lectura en una versión histórica de la base de datos mediante la interfaz sqlite3_snapshot_open(). Si la instantánea histórica ya no está disponible, la transacción de lectura fallará con SQLITE_ERROR_SNAPSHOT. Este código de error solo es posible si SQLite se compila con -DSQLITE_ENABLE_SNAPSHOT.

Explicación oficial · Texto original

The SQLITE_ERROR_SNAPSHOT result code might be returned when attempting to start a read transaction on an historical version of the database by using the sqlite3_snapshot_open() interface. If the historical snapshot is no longer available, then the read transaction will fail with the SQLITE_ERROR_SNAPSHOT. This error code is only possible if SQLite is compiled with -DSQLITE_ENABLE_SNAPSHOT.
