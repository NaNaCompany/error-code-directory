already exists

다른 표기: errors[].code=already_exists

어떤 문제인가요?

GitHub REST API의 HTTP 422 Validation Failed 응답에서 errors[].code에 포함되는 값입니다. 고유해야 하는 값이 기존 리소스와 중복됩니다.

번역 설명

다른 리소스의 값이 매개변수 중 하나와 동일합니다. 이는 고유 키(예: 라벨 이름)가 있어야 하는 리소스에서 발생할 수 있습니다.

Google Translate · 자동 번역입니다. 기술 용어와 적용 조건은 영문 원문을 확인하세요.

공식 설명 · 원문

Another resource has the same value as one of your parameters. This can happen in resources that must have some unique key (such as label names).

해결·진단 링크
