ERROR_INSTALL_SERVICE_SAFEBOOT

다른 표기: 0x00000674 · 0x674 · ERROR_INSTALL_SERVICE_SAFEBOOT · 0x80070674

어떤 문제인가요?

MsiExec.exe·InstMsi.exe의 반환 코드. MSI 메시지 번호와 구분해야 함. 기호: ERROR_INSTALL_SERVICE_SAFEBOOT.

번역 설명

컴퓨터가 *안전 모드*에 있으면 Windows Installer에 액세스할 수 없습니다. 안전 모드를 종료하고 다시 시도하거나 시스템 복원을 사용하여 컴퓨터를 이전 상태로 되돌려보세요. Windows Installer 버전 4.0부터 사용할 수 있습니다.

Google Translate · 자동 번역입니다. 기술 용어와 적용 조건은 영문 원문을 확인하세요.

공식 설명 · 원문

Windows Installer isn't accessible when the computer is in *Safe Mode*. Exit Safe Mode and try again or try using system restore to return your computer to a previous state. Available beginning with Windows Installer version 4.0.
