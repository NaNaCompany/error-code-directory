AADSTS50017

CertificateValidationFailed

다른 표기: 50017

어떤 문제인가요?

Microsoft Entra ID 로그인·토큰 발급 과정에서 기록된 AADSTS50017입니다. 오류 원문과 테넌트의 로그인 로그를 함께 확인하세요.

번역 설명

CertificateValidationFailed - 인증 유효성 검사가 실패했습니다. 다음과 같은 이유로 인해: 신뢰할 수 있는 인증서 목록에서 발급 인증서를 찾을 수 없습니다. 예상 CrlSegment를 찾을 수 없습니다. 신뢰할 수 있는 인증서 목록에서 발급 인증서를 찾을 수 없습니다. 델타 CRL 배포 지점이 해당 CRL 배포 지점 없이 구성되었습니다. 시간 초과 문제로 인해 유효한 CRL 세그먼트를 검색할 수 없습니다. CRL을 다운로드할 수 없습니다. 테넌트 관리자에게 문의하세요.

Google Translate · 자동 번역입니다. 기술 용어와 적용 조건은 영문 원문을 확인하세요.

공식 설명 · 원문

CertificateValidationFailed - Certification validation failed, reasons for the following reasons: Cannot find issuing certificate in trusted certificates list Unable to find expected CrlSegment Cannot find issuing certificate in trusted certificates list Delta CRL distribution point is configured without a corresponding CRL distribution point Unable to retrieve valid CRL segments because of a timeout issue Unable to download CRL Contact the tenant admin.
