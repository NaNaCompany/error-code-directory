1102

Error 1102: Worker exceeded resource limits

다른 표기: Error 1102

어떤 문제인가요?

Cloudflare를 사용하는 웹사이트에 접속하거나 Cloudflare 서비스를 처리할 때 표시되는 1102입니다. 사이트 방문자와 사이트 운영자의 조치가 다르므로 공식 해결 절차의 역할 구분을 확인하세요.

공식 설명 · 원문

This error indicates that a Cloudflare Worker has exceeded its CPU time limit or memory limit. A Cloudflare Worker exceeds a CPU time limit. CPU time is the time spent executing code (for example, loops, parsing JSON, etc). Time spent on network requests (fetching, responding) does not count towards CPU time.

해결·진단 링크

문서의 제품·버전·발생 환경이 현재 상황과 일치하는지 먼저 확인하세요.
