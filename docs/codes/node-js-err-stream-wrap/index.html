ERR_STREAM_WRAP

stream wrap

어떤 문제인가요?

Node.js 스트림을 읽거나 쓰는 과정에서 보고한 오류입니다. 스트림 상태와 공식 설명을 확인하세요.

번역 설명

문자열 디코더가 Socket에 설정되어 있거나 디코더가 objectMode에 있는 경우 중단을 방지합니다.

Google Translate · 자동 번역입니다. 기술 용어와 적용 조건은 영문 원문을 확인하세요.

공식 설명 · 원문

Prevents an abort if a string decoder was set on the Socket or if the decoder is in objectMode.
