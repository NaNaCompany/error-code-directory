어떤 문제인가요?

SQLite가 반환하거나 오류 로그로 보고하는 결과 코드 2입니다. 확장 코드는 기본 코드와 함께 확인하세요.

번역 설명

SQLITE_INTERNAL 결과 코드는 내부 오작동을 나타냅니다. SQLite의 작업 버전에서는 애플리케이션이 이 결과 코드를 볼 수 없습니다. 애플리케이션이 이 결과 코드를 발견하면 데이터베이스 엔진에 버그가 있음을 나타냅니다. 이 결과 코드는 SQLite의 버그로 인해 발생할 수 있습니다. 그러나 애플리케이션 정의 SQL 함수, 가상 테이블, VFS 또는 기타 확장으로 인해 이 결과 코드가 반환될 수도 있으므로 문제가 핵심 SQLite의 결함이 아닐 수도 있습니다.

공식 설명 · 원문

The SQLITE_INTERNAL result code indicates an internal malfunction. In a working version of SQLite, an application should never see this result code. If application does encounter this result code, it shows that there is a bug in the database engine. This result code might be caused by a bug in SQLite. However, application-defined SQL functions or virtual tables, or VFSes, or other extensions can also cause this result code to be returned, so the problem might not be the fault of the core SQLite.
