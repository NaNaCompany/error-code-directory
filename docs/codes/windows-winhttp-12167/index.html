ERROR_WINHTTP_UNABLE_TO_DOWNLOAD_SCRIPT

다른 표기: 0x00002F87 · 0x2F87 · ERROR_WINHTTP_UNABLE_TO_DOWNLOAD_SCRIPT

어떤 문제인가요?

Windows WinHTTP API 호출 중 반환된 코드. 운영체제 지원 범위와 상세 조건은 원문 설명 확인. 기호: ERROR_WINHTTP_UNABLE_TO_DOWNLOAD_SCRIPT.

공식 설명 · 원문

The PAC file cannot be downloaded. For example, the server referenced by the PAC URL may not have been reachable, or the server returned a 404 NOT FOUND response.
