번역 설명

SQLITE_MISMATCH 오류 코드는 데이터 유형 불일치를 나타냅니다. SQLite는 일반적으로 값 유형과 해당 값이 저장될 컨테이너의 선언된 유형 간의 불일치에 대해 매우 관대합니다. 예를 들어 SQLite를 사용하면 애플리케이션이 BOOLEAN 유형으로 선언된 열에 대규모 BLOB를 저장할 수 있습니다. 그러나 어떤 경우에는 SQLite가 유형에 대해 엄격합니다. 유형이 일치하지 않는 경우에는 SQLITE_MISMATCH 오류가 반환됩니다. 테이블의 rowid는 정수여야 합니다. rowid를 정수(또는 다음 사용 가능한 정수 rowid로 자동 변환되는 NULL) 이외의 다른 값으로 설정하려고 하면 SQLITE_MISMATCH 오류가 발생합니다.

공식 설명 · 원문

The SQLITE_MISMATCH error code indicates a datatype mismatch. SQLite is normally very forgiving about mismatches between the type of a value and the declared type of the container in which that value is to be stored. For example, SQLite allows the application to store a large BLOB in a column with a declared type of BOOLEAN. But in a few cases, SQLite is strict about types. The SQLITE_MISMATCH error is returned in those few cases when the types do not match. The rowid of a table must be an integer. Attempt to set the rowid to anything other than an integer (or a NULL which will be automatically converted into the next available integer rowid) results in an SQLITE_MISMATCH error.
