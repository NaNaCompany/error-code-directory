ERR_RX_MEMORY_NOT_SUPPORTED

rx memory not supported

어떤 문제인가요?

Node.js 런타임 또는 API 호출에서 보고한 오류. 공식 설명과 호출 인수, 스택 추적을 함께 확인하세요.

번역 설명

실행 가능 메모리의 런타임 할당이 필요한 기능이 해당 기능을 사용할 수 없는 환경에서 사용되었습니다. 여기에는 적합한 FFI Fast API 함수를 생성하거나 libffi가 클로저를 제공할 수 없고 실행 가능한 메모리를 사용할 수 없을 때 FFI 콜백을 할당하는 것이 포함됩니다. Node.js는 이러한 작업에 대해 생성되지 않은 코드 대체를 보장하지 않습니다. 이 오류는 프로세스를 종료하지 않고도 잡을 수 있습니다.

Google Translate · 자동 번역입니다. 기술 용어와 적용 조건은 영문 원문을 확인하세요.

공식 설명 · 원문

A feature requiring runtime allocation of executable memory was used in an environment where that capability is unavailable. This includes creating an otherwise eligible FFI Fast API function, or allocating an FFI callback when libffi cannot provide a closure and executable memory is unavailable. Node.js does not guarantee a non-generated-code fallback for these operations. This error can be caught without terminating the process.
