번역 설명

SQLITE_ABORT 결과 코드는 일반적으로 응용 프로그램 요청에 의해 작업이 완료되기 전에 중단되었음을 나타냅니다. 참조: SQLITE_INTERRUPT. sqlite3_exec()에 대한 콜백 함수가 0이 아닌 값을 반환하면 sqlite3_exec()는 SQLITE_ABORT를 반환합니다. ROLLBACK 작업이 보류 중인 읽기 또는 쓰기와 동일한 데이터베이스 연결에서 발생하면 보류 중인 읽기 또는 쓰기가 SQLITE_ABORT 또는 SQLITE_ABORT_ROLLBACK 오류로 인해 실패할 수 있습니다. 결과 코드인 것 외에도 SQLITE_ABORT 값은 sqlite3_vtab_on_conflect() 인터페이스에서 반환된 충돌 해결 모드로도 사용됩니다.

공식 설명 · 원문

The SQLITE_ABORT result code indicates that an operation was aborted prior to completion, usually by application request. See also: SQLITE_INTERRUPT. If the callback function to sqlite3_exec() returns non-zero, then sqlite3_exec() will return SQLITE_ABORT. If a ROLLBACK operation occurs on the same database connection as a pending read or write, then the pending read or write may fail with an SQLITE_ABORT or SQLITE_ABORT_ROLLBACK error. In addition to being a result code, the SQLITE_ABORT value is also used as a conflict resolution mode returned from the sqlite3_vtab_on_conflict() interface.
