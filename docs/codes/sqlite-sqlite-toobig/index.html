번역 설명

SQLITE_TOOBIG 오류 코드는 문자열이나 BLOB가 너무 컸음을 나타냅니다. SQLite의 문자열 또는 BLOB의 기본 최대 길이는 1,000,000,000바이트입니다. 이 최대 길이는 SQLITE_MAX_LENGTH 컴파일 타임 옵션을 사용하여 컴파일 타임에 변경하거나 sqlite3_limit(db,SQLITE_LIMIT_LENGTH,...) 인터페이스를 사용하여 런타임에 변경할 수 있습니다. SQLITE_TOOBIG 오류는 SQLite가 컴파일 시간 또는 런타임 제한을 초과하는 문자열 또는 BLOB를 발견할 때 발생합니다. SQLITE_TOOBIG 오류 코드는 너무 큰 SQL 문이 sqlite3_prepare_v2() 인터페이스 중 하나에 전달될 때 발생할 수도 있습니다. SQL 문의 최대 길이는 기본적으로 유사한 값인 1,000,000,000바이트로 설정됩니다. 최대 SQL 문 길이는 컴파일 타임에 SQLITE_MAX_SQL_LENGTH를 사용하거나 런타임에 sqlite3_limit(db,SQLITE_LIMIT_SQL_LENGTH,...)를 사용하여 설정할 수 있습니다.

공식 설명 · 원문

The SQLITE_TOOBIG error code indicates that a string or BLOB was too large. The default maximum length of a string or BLOB in SQLite is 1,000,000,000 bytes. This maximum length can be changed at compile-time using the SQLITE_MAX_LENGTH compile-time option, or at run-time using the sqlite3_limit(db,SQLITE_LIMIT_LENGTH,...) interface. The SQLITE_TOOBIG error results when SQLite encounters a string or BLOB that exceeds the compile-time or run-time limit. The SQLITE_TOOBIG error code can also result when an oversized SQL statement is passed into one of the sqlite3_prepare_v2() interfaces. The maximum length of an SQL statement defaults to a similar value of 1,000,000,000 bytes. The maximum SQL statement length can be set at compile-time using SQLITE_MAX_SQL_LENGTH or at run-time using sqlite3_limit(db,SQLITE_LIMIT_SQL_LENGTH,...).
