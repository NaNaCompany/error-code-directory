    Error 1102: Worker exceeded resource limits

    Cette erreur indique qu'un Cloudflare Worker a dépassé sa limite de temps CPU ou sa limite de mémoire. Un Cloudflare Worker dépasse une limite de temps CPU. Le temps CPU est le temps passé à exécuter du code (par exemple, boucles, analyse JSON, etc.). Le temps passé sur les requêtes réseau (récupération, réponse) ne compte pas dans le temps CPU.

    CloudflareCloudflare HTTP errors

Cette erreur peut se produire si un e-mail a été ajouté avec une variante de l'e-mail que vous essayez d'ajouter.
