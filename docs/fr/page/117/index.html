  • BaseExceptionGroup
    BaseExceptionGroup

    Ces deux types d'exceptions encadrent les exceptions dans la séquence excs. Le paramètre msg doit être une chaîne. La différence entre les deux classes est que BaseExceptionGroup étend BaseException et qu'il peut envelopper n'importe quelle exception, tandis qu'ExceptionGroup étend Exception et il ne peut envelopper que les sous-classes d'Exception. Ce design est de sorte que sauf Exception capture un ExceptionGroup mais non BaseExceptionGroup. Le constructeur BaseExceptionGroup retourne un ExceptionGroup plutôt qu'un BaseExceptionGroup si toutes les exceptions contenues sont des cas d'Exception, de sorte qu'il peut être utilisé pour rendre la sélection automatique. Le constructeur ExceptionGroup, d'autre part, soulève un TypeError si une exception contenue n'est pas une sous-classe d'Exception. Les groupes d'exception sont génériques sur le type de leurs exceptions contenues. Notez que BaseExceptionGroup définit __new_(() ), donc les sous-classes qui ont besoin d'une signature de constructeur différente doivent surpasser cela plutôt que __init__(). Par exemple, ce qui suit définit une sous-classe de groupe d'exception qui accepte un code exit_et construit le message de groupe à partir de celui-ci. Comme ExceptionGroup, toute sous-classe de BaseExceptionGroup qui est aussi une sous-classe d'Exception ne peut envelopper que des instances d'Exception.
