Code SQLITE_IOERR_MMAP · Problème signalé par SQLite.

Explication traduite

Le code d'erreur SQLITE_IOERR_MMAP est un code d'erreur étendu pour SQLITE_IOERR indiquant une erreur d'E/S dans les méthodes xFetch ou xUnfetch sur l'objet sqlite3_io_methods tout en essayant de mapper ou de démapper une partie du fichier de base de données dans l'espace d'adresse du processus.

Explication officielle · Texte d’origine

The SQLITE_IOERR_MMAP error code is an extended error code for SQLITE_IOERR indicating an I/O error within the xFetch or xUnfetch methods on the sqlite3_io_methods object while trying to map or unmap part of the database file into the process address space.
