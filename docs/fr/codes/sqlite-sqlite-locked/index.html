Quel problème ce code indique-t-il ?

Code SQLITE_LOCKED · Problème signalé par SQLite.

Explication traduite

Le code de résultat SQLITE_LOCKED indique qu'une opération d'écriture ne peut pas se poursuivre à cause d'un conflit dans la même connexion de base de données ou d'un conflit avec une autre connexion de base de données qui utilise un cache partagé. Par exemple, une instruction DROP TABLE ne peut pas être exécutée alors qu'un autre thread est lu à partir de cette table sur la même connexion de base de données parce qu'en laissant tomber la table supprimerait la table sous le lecteur concurrent. Le code de résultat SQLITE_LOCKED diffère de SQLITE_BUSY dans ce cas SQLITE_LOCKED indique un conflit sur la même connexion de base de données (ou sur une connexion avec un cache partagé) tandis que SQLITE_BUSY indique un conflit avec une connexion de base de données différente, probablement dans un processus différent.

Explication officielle · Texte d’origine

The SQLITE_LOCKED result code indicates that a write operation could not continue because of a conflict within the same database connection or a conflict with a different database connection that uses a shared cache. For example, a DROP TABLE statement cannot be run while another thread is reading from that table on the same database connection because dropping the table would delete the table out from under the concurrent reader. The SQLITE_LOCKED result code differs from SQLITE_BUSY in that SQLITE_LOCKED indicates a conflict on the same database connection (or on a connection with a shared cache) whereas SQLITE_BUSY indicates a conflict with a different database connection, probably in a different process.
