6704

ERROR_TRANSACTION_ALREADY_ABORTED

Autres notations : 0x00001A30 · 0x1A30 · ERROR_TRANSACTION_ALREADY_ABORTED · 0x80071A30

Quel problème ce code indique-t-il ?

Code 6704 · Problème signalé par Windows Win32.

Explication traduite

Il est trop tard pour effectuer l'opération demandée, puisque l'opération a déjà été interrompue.

OPUS-MT · Helsinki-NLP / CTranslate2 · Il s’agit d’une traduction automatique. Consultez l’original anglais pour les termes techniques et les conditions applicables.

Explication officielle · Texte d’origine

It is too late to perform the requested operation, since the Transaction has already been aborted.
