Quel problème ce code indique-t-il ?

Code auth/invalid-disabled-field · Problème signalé par Firebase Authentication Admin SDK.

Explication traduite

La valeur fournie pour la propriété d'utilisateur désactivé n'est pas valide. Ce doit être un booléen.
