Quel problème ce code indique-t-il ?

Code AADSTS50020 · Problème signalé par Microsoft Entra ID.

Explication traduite

UtilisateurNon autorisé - Les utilisateurs ne sont pas autorisés à appeler cet endpoint. Le compte utilisateur '{email}' du fournisseur d'identité '{idp}' n'existe pas dans le locataire '{tenant}' et ne peut pas accéder à l'application '{appid}'({appName}) dans ce locataire. Ce compte doit être ajouté en tant qu'utilisateur externe dans le locataire d'abord. Connectez-vous et connectez-vous à nouveau avec un compte utilisateur Microsoft Entra différent. Si cet utilisateur doit être membre du locataire, il doit être invité via le système B2B. Pour plus d'informations, visitez AADSTS50020.

OPUS-MT · Helsinki-NLP / CTranslate2 · Il s’agit d’une traduction automatique. Consultez l’original anglais pour les termes techniques et les conditions applicables.

Explication officielle · Texte d’origine

UserUnauthorized - Users are unauthorized to call this endpoint. User account '{email}' from identity provider '{idp}' does not exist in tenant '{tenant}' and cannot access the application '{appid}'({appName}) in that tenant. This account needs to be added as an external user in the tenant first. Sign out and sign in again with a different Microsoft Entra user account. If this user should be a member of the tenant, they should be invited via the B2B system. For additional information, visit AADSTS50020.
